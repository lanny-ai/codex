# OS Cortex AEO Publisher — Start Here

This package installs a reusable AEO authority-publishing workflow into the ChatGPT desktop/Codex app. Every member uses their own ChatGPT account, computer, domain, Sites project, credentials, analytics properties, and Git project.

Business-workspace administrators may restrict plugin installation. If the marketplace or Install control is unavailable, ask that workspace's administrator to approve it or use an eligible personal workspace for the workshop.

## What this package does

- Onboards one client brand into an isolated project.
- Builds or expands one authority website instead of producing daily microsites.
- Researches and scores important audience questions.
- Drafts evidence-backed answer pages with claim-level citations.
- Quarantines any run that fails a hard quality gate.
- Supports scheduled daily publishing after three supervised passes.
- Measures citation and traffic signals when optional connections are configured.

## Install on macOS

1. Install and sign in to the ChatGPT desktop/Codex app.
2. Install the Sites plugin from Plugins.
3. Open Terminal and run `codex plugin marketplace add lanny-ai/codex --ref main`.
4. If you are installing from the workshop ZIP before the Git repository is published, unzip it and run `bash install-mac.sh` instead.
5. Restart ChatGPT desktop.
6. Open Plugins, select **OS Cortex AEO Systems**, and install **OS Cortex AEO Publisher**.
7. Start a new task and say: `Use $aeo-client-onboarding to set up my brand.`

## Install on Windows

1. Install and sign in to the ChatGPT desktop/Codex app.
2. Install the Sites plugin from Plugins.
3. Open PowerShell and run `codex plugin marketplace add lanny-ai/codex --ref main`.
4. If you are installing from the workshop ZIP before the Git repository is published, unzip it and run `powershell -ExecutionPolicy Bypass -File .\install-windows.ps1` instead.
5. Restart ChatGPT desktop.
6. Open Plugins, select **OS Cortex AEO Systems**, and install **OS Cortex AEO Publisher**.
7. Start a new task and say: `Use $aeo-client-onboarding to set up my brand.`

## Launch sequence

1. Complete the client intake.
2. Connect the domain and build the authority hub.
3. Publish three supervised answer pages.
4. Establish the 25-question baseline.
5. Activate the daily schedule only after all gates pass.
6. Observe the first 14 unattended runs.

## Important boundaries

- Never paste API keys into ordinary chat messages or commit them to Git.
- Do not reuse another client's configuration or Sites project.
- API citation samples do not prove consumer-app rankings.
- Local schedules require the computer and ChatGPT desktop app to remain running.
- The member edition starts supervised; automatic public publishing is enabled only after acceptance.
