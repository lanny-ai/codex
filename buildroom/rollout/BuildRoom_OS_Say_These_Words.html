If a session says something is missing

Run the missing session first. Almost always right. The navigator names it.

Or take the provisional path. A five-minute interview stands in. The output is marked provisional and the Viewer keeps flagging it until the real session runs.

The one habit

Never re-explain your business. Every session reads your Business File first and hands it back updated. Replace your saved copy every time.

If a session asks something the file already answers, say: Read my Business File first.
