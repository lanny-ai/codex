The Build Room OS

A membership that used to hand out weekly prompt files now runs on one system: a file that remembers your business, ten guided build sessions that read it, and a pipeline that turns new curriculum into installable skills in an afternoon.

The promise to members: you never re-explain your business to Claude again. Every session opens by reading your Business File, skips every question it already answers, and hands the file back updated. Session one interviews you. Session four already knows your avatar, offer, and positioning — and just builds.

The three parts

1 · The Business File

One member-owned markdown document, eleven sections (avatar, offer, positioning, funnel, SOPs, role, training…). Every section carries a status — not started / provisional / complete — so the system knows what's load-bearing. Member edits always win. Stays under ~2,500 words.

2 · Ten skills

Guided sessions installed in Claude Cowork. Each reads the file, runs the week's curriculum one question at a time, delivers a finished asset, and writes its section back. A navigator skill tells members exactly what to run next.

3 · The production pipeline

Author a knowledge base + five-prompt system in the house format, run one command, resolve the review markers, ship. The build refuses to package anything unreviewed. Three September weeks went from blank to installable this way.

Also in the kit

  • Member install bundle — one ZIP: all ten skills, the Quick Start, the calculator, the blank Business File. Install is Settings → Skills → Upload.

  • Test run + findings — the system was run end to end on AI Momentum Labs itself; six ranked findings are documented, the top one being that AI-generated "verbatim" client language needs a provenance flag before it reaches a landing page.

Where it stands

  • Roadmap coverage went from 6 of 36 weeks to 9 of 36; the remaining weeks are now a generator run plus a review pass each.
