The Build Room OS

A membership that used to hand out weekly prompt files now runs on one system: a file that remembers your business, ten guided build sessions that read it, and a pipeline that turns new curriculum into installable skills in an afternoon.

The promise to members: you never re-explain your business to Claude again. Every session opens by reading your Business File, skips every question it already answers, and hands the file back updated. Session one interviews you. Session four already knows your avatar, offer, and positioning — and just builds.

The three parts

1 · The Business File

One member-owned markdown document, twenty sections (avatar, offer, positioning, funnel, SOPs, role, training, weekly ops, build plan, lead gen, sales, advertising, video…). Every section carries a status — not started / provisional / complete — so the system knows what's load-bearing. Member edits always win. Stays under ~2,500 words.

2 · Thirty-one skills

Guided sessions that run in Claude Code or Codex. Each reads the file, runs the week's curriculum one question at a time, delivers a finished asset, and writes its section back. A navigator skill tells members exactly what to run next.

3 · The production pipeline

Author a knowledge base + five-prompt system in the house format, run one command, resolve the review markers, ship. The build refuses to package anything unreviewed. All four September weeks and both brainstorm tools went from blank to installable this way.

Also in the kit

  • The Rent Calculator — one-page tool: score your processes, see hours and dollars locked in your head, copy a §9 block straight into your file.
  • The Business File Viewer — one-page tool: paste your file, see every section's status, your progress, the navigator's next step, and your Build Plan with stale ideas flagged. No AI call; runs entirely in the browser.
  • The Brainstorm Board — one-page tool: frame, diverge on a timer, cluster, dot-vote, decide, and copy the whole board into Claude for capture.
  • Member install bundle — one ZIP: all thirty-one skills, the Quick Start, the printable guide, three tools, the blank Business File. Install is: unzip, open Claude Code or Codex in the folder.
  • Facilitator run-of-show — a 60-minute launch session built around two live demos, including the moment a session skips the whole interview.
  • Test run + findings — the system was run end to end on AI Momentum Labs itself; six ranked findings are documented, the top one being that AI-generated "verbatim" client language needs a provenance flag before it reaches a landing page.
