PROMPT 2 — OBSTACLE MAP + DELIVERABLES BUILD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

---

Run the Hormozi obstacle audit on my ICA's path to the dream outcome.

STEP 1 — COMPLETE OBSTACLE LIST:
List every single reason my ICA might NOT achieve the dream outcome —
even if the obstacle is on their side (mindset, time, skills).
Include: internal obstacles, external obstacles, execution obstacles,
relationship/buy-in obstacles, and past-failure obstacles.
Be thorough. The more you list, the better the offer we can build.

STEP 2 — DELIVERABLES MAPPED TO OBSTACLES:
For each obstacle, name a specific deliverable that eliminates it.
Format:
Obstacle: [What would stop them]
Deliverable: [What you include to remove that obstacle]
Value it creates: [What becomes possible because this obstacle is gone]

STEP 3 — TRIM & STACK:
Review the complete deliverables list.
Flag: which are high perceived value / low delivery cost? (KEEP)
Flag: which are low perceived value / high delivery cost? (CUT or RESTRUCTURE)
Flag: which are table-stakes (expected but not differentiating)? (INCLUDE but don't lead with)

STEP 4 — VALUE-FORWARD NAMING:
Rename all KEEP deliverables using transformation language.
Not: "Weekly call" — But: [Name that signals the outcome of that call]
Not: "Resource library" — But: [Name that signals what resources unlock]
Give each deliverable a name a client would be excited to receive.

PROMPT 3 — VALUE STACK + PRICING ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

---

Build the complete pricing architecture using anchoring, value stacking,
and loss aversion principles from the knowledge base.

PART A — THE VALUE STACK:
For each deliverable in the offer:
- Name (value-forward, from Prompt 2)
- What it is (one sentence)
- Perceived standalone value ($)
- Why someone would pay that much for it alone

Then: Total perceived value of all components combined: $
Then: My actual investment: $
Then: Value-to-investment multiple: Xx

PART B — THE THREE PRICE ANCHORS:
Anchor 1 — COST OF THE PROBLEM:
What is this problem costing the ICA each month in lost revenue,
wasted time, or unrealized opportunity?
Do the math. Write a 3-sentence script that surfaces this.

Anchor 2 — THE ALTERNATIVE COST:
What would it cost them to solve this problem another way?
(Hire staff, piece together tools, agencies, consulting, doing it themselves)
Write a 2-sentence comparison.

Anchor 3 — THE TRANSFORMATION ROI:
If the offer delivers as promised, what is that result worth
over 12 months to their business? Calculate it.
Write 2 sentences framing the investment as a fraction of the return.

PART C — THE PRICING TIERS (decoy effect in action):
Design 3 tiers:
CORE: [Name] — [What's included] — [Price]
PREMIUM: [Name] — [What's added] — [Price: 2-3x Core]
ACCELERATOR: [Name] — [White glove, DFY, highest touch] — [Price: 4-5x Core]

Note which tier you EXPECT most people to choose.
Explain how the presence of the other tiers changes the psychology.

PART D — THE PRICE REVEAL SCRIPT:
Using all three anchors, write the 6-8 sentence sequence for
presenting the investment on a sales call or offer page.
The price should be the last sentence. Everything before it
should make the price feel like the obvious, low-risk decision.

PROMPT 4 — OUTCOME PROMISE + TRANSFORMATION LANGUAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

---

Build the transformation language system — every version of the
outcome promise across different formats and contexts.

THE BEFORE/AFTER BRIDGE (the emotional core of the offer):
BEFORE (4-5 sentences):
The honest, specific, vivid picture of where the ICA is now.
Not generic — use the specific language from the ICA profile.
This should make the ICA feel seen, not sold to.

AFTER (4-5 sentences):
The specific, visual, emotionally resonant picture of where
they are after the offer delivers. Numbers where possible.
Concrete life details. Not "freedom and success" — actual Tuesday morning.

THE IDENTITY SHIFT STATEMENT:
"Before: someone who _____. After: someone who _____."
Write 3 versions. The third should be the most emotionally true.

THE PROOF-OF-CONCEPT SENTENCE:
One sentence that uses a real result (or realistic result) to
make the outcome feel achievable — not aspirational.
"Within 90 days, [name] went from [before] to [after]."

10 OUTCOME PROMISE VARIATIONS:
Using different frameworks from the knowledge base:
Versions 1-2: Outcome-forward
Versions 3-4: Problem-escape forward
Versions 5-6: Identity-transformation forward
Versions 7-8: Specific ICA language (pulled from your ICA document)
Versions 9-10: MAGIC formula naming variants

Your recommendation: which is strongest and why?

Your recommendation: Which is the right guarantee for my current
stage and delivery confidence? Why?

PART B — THE COMPLETE OFFER SUMMARY:
Write a clean one-page summary of the final offer:
- Offer name
- Core transformation promise
- Who it's for (best-fit profile)
- Phase overview (3 phases, one sentence each)
- What's included (named deliverables, value-forward)
- Investment (all 3 tiers)
- Guarantee

This is the reference document for everything going forward.

PART C — THE 60-SECOND PITCH SYSTEM:
Write 3 versions:

VERSION 1 — NETWORKING / CASUAL:
How to answer "what do you do?" at an event.
Natural, conversational. Ends with them asking a follow-up.

VERSION 2 — SALES CALL OPENER:
The first 90 seconds of a discovery call.
Sets the frame. Communicates the transformation.
Creates space for them to share their situation.

VERSION 3 — CONTENT / SOCIAL BIO:
30 words or less. Website hero, LinkedIn bio, or social intro.
Punchy, specific, clear.
