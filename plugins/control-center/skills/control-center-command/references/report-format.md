# Phone-shaped report format

```
✅ <command restated in ≤8 words>

Done
- <action> → <artifact/link>
- <action> → <artifact/link>

Needs you
- <decision> (reply yes/no)

Notes
- <anything surprising, or "none">
```

Rules: five lines of "Done" maximum — collapse the rest into a link to the log. Never paste a long document into the report; write it to a file and link it. If nothing needs a decision, drop the "Needs you" block entirely.
