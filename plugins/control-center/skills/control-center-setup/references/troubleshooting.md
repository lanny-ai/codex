# When it breaks

**Your first move is always: fix it yourself, then explain in one line.** Never make them read an error message.

Say: *"That's on me — one sec."* Never: *"It looks like you entered it wrong."*

## The five things that actually go wrong

**1. The sign-in window didn't stick.**
→ Redo the connection once, quietly. If it fails again: *"That sign-in's being stubborn. Let's do it in your browser instead — 20 seconds."*

**2. The private code doesn't work.**
→ Don't ask them to read it back. *"That code didn't take. Grab a fresh one from the same page and paste it — 20 seconds."*

**3. Something needs installing and they don't have it.**
→ Install it for them. Tell them what it does in six words: *"Installing the thing that drives browsers…"* Never show them install output.

**4. The phone test doesn't come back.**
→ Check they're signed in on the phone with the **same account** first — that's the cause 9 times out of 10. Then check the computer is awake. Then fall back to the cloud path and say: *"Switched it to the cloud version — works even with your laptop closed."*

**5. A connection just won't cooperate.**
→ Park it. Finish everything else. Come back at the very end. Never let one broken connection stall the whole setup. Say: *"Parking that one — everything else is working. I'll sort it at the end."*

## If they get overwhelmed
Offer the two escape hatches:
> *"Want me to just pick the normal setup and finish it? Type **go**. Or type **stop** and we'll pick this up later exactly where we are."*

If they type **go**, make every remaining choice yourself, finish, and hand them the card. Don't ask anything else.
